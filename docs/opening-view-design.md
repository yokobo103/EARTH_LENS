# Opening observation view

v0.4 starts a fresh, non-shared visit over the Singapore region with Terrain, Shipping, Ports, Cable connections, and Chokepoints visible. A collapsed observation card names the region and leaves `WHY HERE?` as the first question; the scan is never run automatically. This is the selected opening candidate because it makes several systems overlap without revealing a mission answer.

Shared URLs retain their encoded camera, lenses, selection, mode, language, and time state and never receive this opening override. The ABOUT entry appears before this view only on the first non-shared visit; it can be reopened from the header tools menu.

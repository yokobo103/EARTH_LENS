## SCALERANK は使えるか

河川や港ほど壊れてはいない。面積とはゆるく相関する。

```
rank 1  n= 14  面積の中央値 587,255 km2
rank 2  n= 33          241,997
rank 3  n= 61          159,119
rank 4  n= 66           64,082
rank 5  n=107           33,535
rank 6  n= 13           21,228
```

だが**「越えにくさ」とは相関しない。** ETOPO 2022（60秒グリッド）を全294件に当てて実測した。

| 地物 | NE class | SCALERANK | 標高の中央値 | 2,000m以上の面積 |
|---|---|---:|---:|---:|
| カラコルム山脈 | Range/mtn | **2** | **5,106 m** | 111,215 km² |
| 崑崙山脈 | Range/mtn | **2** | 4,734 m | 302,072 km² |
| パミール高原 | Range/mtn | **2** | 4,175 m | 93,356 km² |
| アルティプラーノ | Plateau | **3** | 4,005 m | 342,005 km² |
| — | | | | |
| ウェスタン・プラトー（豪） | Plateau | **1** | **445 m** | **0 km²** |
| グレートディヴァイディング山脈 | Range/mtn | **1** | 365 m | 22 km² |
| ウラル山脈 | Range/mtn | **1** | 401 m | 0 km² |
| イベリア半島 | Plateau | **1** | 620 m | 3,350 km² |

**標高の中央値 5,106 m のカラコルムが rank 2、445 m のオーストラリアの台地が rank 1。**
河川のトンガリロ川と同じ構図がここにもある。ただし程度は軽く、
rank 1 の14件のうち破綻しているのは4件で、アンデス・チベット・ロッキー・
ヒマラヤ・天山・アルプス・コーカサスは正しく rank 1 に入っている。

**結論: 世界段の名簿としてはそのまま使えない。ただし全面的に捨てる必要もない。**

## 山脈と高原を同じレンズに置いてよいか

**NE の class は「越えにくさ」を予測しない。** 実測すると、上位45件のうち16件で
class と標高の読みが食い違う。

```
Plateau なのに低い    ブラジル高原 445m / 中央シベリア高原 345m / デカン高原 492m
                     モンゴル高原 1,203m / ロエス（黄土）高原 1,436m
Range/mtn なのに高い面  カラコルム 5,106m / 崑崙 4,734m / パミール 4,175m / 祁連 3,644m
```

分かれ目は class ではなく**高さ**だった。

ただし、**残すべき区別はある。** 高い地面には2種類ある。

| | 低い所（p10） | 高い所（p90） | 差 |
|---|---:|---:|---:|
| チベット高原 | 2,645 m | 5,254 m | 2,609 m |
| アルティプラーノ | 3,653 m | 4,695 m | 1,042 m |
| カラコルム | 3,668 m | 5,706 m | 2,038 m |
| — | | | |
| アンデス | **243 m** | 4,186 m | 3,943 m |
| ヒマラヤ | 1,226 m | 5,365 m | 4,139 m |
| ヒンドゥークシュ | 1,159 m | 4,735 m | 3,576 m |

**低い所も高いなら「高い面」（人が上で暮らす）、低い所が平地なら「壁」（人が越える）。**
チベットとアルティプラーノは面、アンデスとヒマラヤは壁。

この区別は NE の class とは別物で、実測で出せる。ただし境目の置き方は詰め切れていない
（コロラド高原 p10 1,475m、雲貴高原 p10 1,042m あたりが曖昧）。

## 何で測るべきか

**「一番高い山」ではなく「越えにくい高い地面がどれだけ広いか」。**
最高標高だけだと、小さな高峰が巨大なアンデスと同格になる。

`ある高さ以上の面積` が最もよく効いた。面積だけ、標高だけ、では足りない。

```
面積だけで並べると        ブラジル高原(3.9M km2) が ヒマラヤ(0.47M km2) の8倍強い
標高の中央値だけで並べると  カラコルム(5,106m) が アンデス(1,611m) より強い
2,000m以上の面積で並べると  チベット > アンデス > ロッキー > ヒマラヤ > アルティプラーノ
```

面積が巨大でも高い所が無い地物は、きれいに落ちる。

```
ブラジル高原      面積 3,906,404 km2  2,000m以上 243 km2 (0.0%)  中央値 445m
中央シベリア高原  面積 2,180,106 km2  2,000m以上   0 km2         中央値 345m
ウェスタン・プラトー 面積 1,754,537 km2  2,000m以上   0 km2         中央値 445m
アパラチア山脈    面積   848,697 km2  2,000m以上   0 km2         中央値 310m
```

しきい値ごとの件数（南極を含む）:

| 条件 | 件数 |
|---|---:|
| 2,000m以上を 100,000 km² 以上 | **21** |
| 1,000m以上を 100,000 km² 以上 | **48** |
| 1,000m以上を 30,000 km² 以上 | **112** |
| 1,000m以上を 10,000 km² 以上 | 164 |

## 河川方式が使えるか

**使える。実際に通した。**

```
ETOPO 2022 全球 60秒グリッド（約1.9km）  GeoTIFF 466 MB
  → 294件すべてのポリゴン内セルを数える（緯度で面積重み付け）
  → 294 / 294 件に標高の統計が付いた（100%）
処理時間  このPCで数分
```

HydroRIVERS（544 MB）と同じ規模で、同じ手順。DEM はリポジトリに入れず、
派生値だけを焼く。

出典は NOAA NCEI ETOPO 2022（公開データ）。

### 容量と実行時負荷

| 持ち方 | 生 | gzip |
|---|---:|---:|
| 5項目（1000m以上/2000m以上/中央値/p10/p90）× 294件 | 18.7 KB | **4.8 KB** |
| 段番号だけ | 0.6 KB | 0.03 KB |

現在の `physical-features.geojson` は 195 KB。5項目全部持っても gzip で **+2.5%**。

実行時は、河川と同じく段の変わり目に1回の数値比較。いまはポリゴンに距離条件が
無いので、**段を入れると描画は今より軽くなる**（世界表示で294件 → 21件）。

### 南極をどうするか

**極高原は 2,000m以上を 5,926,623 km² 持ち、どの指標でもチベットを抜いて世界一になる。**
タロス・ドームも304,146 km²。

人や物の移動を曲げる地形のレンズなので、`REGION == "Antarctica"` を対象外にするのが
筋だと思う。基準を書いて全部に一貫して当てるので、恣意的な個別調整ではない。
ただし方針判断なので、実装前に決めたい。

## いまの見た目の問題

実測と画面で確認した。

**1. 世界表示で294件すべてが描かれている。** 距離条件が面に無い。

**2. 強弱が無い。** 枠線の太さも不透明度も、面積・標高・rank のどれとも連動していない。

```
Range/mtn  塗り α0.05  枠線 α0.88
Plateau    塗り α0.16  枠線 α0.62
色は両方とも #93a9c9 の1色
```

ヒマラヤ（473,000 km²）と、ナガ丘陵のような小山地が**同じ太さの同じ枠線**で出る。
ヒマラヤ〜チベットを大陸縮尺で見ると、カザフ高地・アルダン高原・ヤブロノイ山脈・
スタノヴォイ山脈・大興安嶺・小興安嶺・チョタナグプル高原・アラカン山脈…が
すべて同じ強さで並ぶ。

**3. 行政界に見える。** 細い閉じた輪郭＋中に名札、という描き方が国境線と同じ語彙。
欧州〜西アジアの縮尺では、アルプス・カルパティア・ディナル・ザグロスに加えて
ヒジャーズ山地・トワイク山地・ジャバル・ビン・ガナイマなどが同じ線で並び、
地形というより区画割りに見える。

**4. 高原の塗りは強すぎない。** チベット高原は淡い面としてよく読める。
むしろ**山脈側が弱すぎて、高原に埋もれている**。ヒマラヤの輪郭はチベットの
南縁と見分けがつきにくい。

**5. スマホでより悪い。** 375px幅でヒマラヤ〜チベットを見ると、
細線のメッシュと20枚前後の名札になる。地形の骨格には見えない。

## 推奨

1. **ETOPO からオフラインで標高の派生値を焼く。** 河川と同じ方式。+4.8 KB gzip。
2. **段は「ある高さ以上の面積」で切る。** 説明文はしきい値そのものになる。
   「この縮尺では、2,000m以上の高地を10万km²以上もつ地形を出しています。
   アパラチア山脈は2,000m以上が0km²なので、もっと寄ると出ます。」
3. **強弱を入れる。** 枠線の太さと不透明度を、高い地面の広さに連動させる。
   いちばん効くのはここで、段を切るより先に効く可能性がある。
4. **描き分けは NE の class ではなく実測の形で決める。**
   低い所も高い＝面として塗る、低い所が平地＝縁として描く。
   ただし境目は要調整。
5. **南極の扱いを先に決める。**

やらないこと: DEM をランタイムに載せる、有名山脈の個別強調。

## 残る論点

- **問いの言い方。** いまのレンズ説明は「人や物の移動を、長く迂回させてきた地形。」
  だが、迂回は他レンズと重ねて気づくことで、このレンズ単体で言えるのは
  「どこに越えにくい高い地面が広がっているか」まで。河川で決めた
  「そのレンズ1枚で成立することだけ言う」に照らすと、書き換えの余地がある。
- **通り道が同じデータに入っている。** 元データには Valley 6件・Basin 9件・
  Lowland 5件・Plain 30件・Gorge 3件・Foothills 3件がある。
  「どこで曲がるか」は壁だけでなく、抜け道の側からも描ける。別レンズか、
  このレンズの一部か、検討の余地がある。

## 実装した内容

`tools/build-terrain-importance.py` が ETOPO から焼く。**理由は2つ、別々に持つ。**

```
high_elevation_extent  高い地面がどれだけ広いか
relief_barrier         周囲の低い地面からどれだけ立ち上がるか
```

総合スコアにはしない。1つの数に畳むと、どちらの理由で出ているのか説明できなくなる。

### 段

| 段 | 条件 | 件数 |
|---|---|---:|
| 世界 | 2,000m以上を 100,000 km2 以上 | 19 |
| 大陸 | ＋ 1,500m以上を 50,000 km2 以上、または 比高 2,000m 以上 | 34 |
| 国 | ＋ 1,000m以上を 30,000 km2 以上、または 比高 900m 以上 | 105 |
| — | どの段にも入らない（南極25件を含む） | 136 |

理由の内訳は high_elevation_extent 92 / relief_barrier 66。

**2つの指標は違うものを拾う。** アルプスは 2,000m 以上が 34,723 km2 しかなく
面積では大陸段に入らないが、比高 2,169m で入る。コーカサス（比高 2,503m）、
ザグロス（2,023m）、エルブールズ（2,089m）、ピレネー（1,868m）も同じ。

### 比高の測り方

`その地物の上位10%の高さ − 周囲の地面の下位25%の高さ`。

周囲は外接矩形を 1.5 度広げた範囲のうちポリゴンの外、海は除く。中央値ではなく
下位25%を使う。ヒマラヤの周りにはガンジス平原とチベット高原の両方があり、
越える側から見て意味があるのは低いほう。

```
ヒマラヤ   上位10% 5,365m − 周囲 241m = 5,125m
アンデス   上位10% 4,186m − 周囲  99m = 4,087m
アルプス   上位10% 2,360m − 周囲 191m = 2,169m
アパラチア 上位10%   625m − 周囲 113m =   512m  → どの段にも入らない
```

### ETOPO は氷床の上面

使っているのは surface（氷の上）で岩盤ではない。実測で、グリーンランドの
サミットが 3,200m、南極のボストークが 3,487m と出る。

この層で氷床の上に乗っているのは **Vatnajokull（アイスランド）1件だけ**で、
グリーンランド氷床の上には0件。その1件も比高で国段に入るだけなので、
岩盤に切り替えても結論は変わらない。南極は下の理由で対象外。

### 南極

`REGION == "Antarctica"` の25件を一律に外した。極高原は 2,000m 以上を
5,926,623 km2 もち、どの指標でもチベットを抜いて世界一になるが、
その上に日常の移動は無い。地物ごとの調整ではなく、書ける基準による一律の除外。

### 見た目

**濃さで強弱を出す。** 段が上ほど濃く塗る（0.34 / 0.26 / 0.16）。
枠線は面より弱くして、国境に見えないようにした（0.5 / 0.36 / 0.24）。

Cesium のポリゴン枠線は WebGL では太さを変えられないので、線ではなく面で強弱を出す。
結果として「輪郭＋名札」から「地形の塊」へ読み方が変わった。

### 容量と負荷

```
physical-features.geojson  195,687 B -> 220026 B（gzip 63959 B）
エンティティ数              301 -> 162（描かない136件を作らない）
世界表示で距離条件を満たす面  294 -> 23
```

実行時は段の比較だけ。ETOPO はランタイムに載せない。

### 画面（本番ビルド・375x812）

- **アンデス**: 南米西岸を縦に貫く1本の淡い帯として出る。ブラジル高原が消えたので内陸が空く
- **アルプス**: 弧を描く塊として読める。名前を知らなくても地形だと分かる
- **ヒマラヤ〜チベット**: 天山・アルタイ・パミール・崑崙・祁連が帯として並び、
  その間のタリム盆地が抜けて見える。以前の細線メッシュではなくなった

最初は塗り 0.3 / 0.2 / 0.12 で作ったが、欧州の大陸表示でアルプスがほとんど見えず、
名札も港に負けていた。濃さを上げ、地形にも名札の重み（65 / 45 / 28）を与えた。

## 将来の「通り道」（今回は追加しない）

同じ元データ `ne_10m_geography_regions_polys` に、壁ではなく**抜け道**の側がある。

```
Plain 30件 / Basin 9件 / Valley 6件 / Lowland 5件 / Gorge 3件 / Foothills 3件
Delta 12件 / Isthmus 4件 / Depression 2件
```

「地形がどこで移動を曲げたか」は、壁だけでなく、そこを抜ける谷や地峡の側からも
描ける。イスマス（地峡）4件はパナマ・スエズと直結する。別レンズにするか、
このレンズの一部にするかは未検討。

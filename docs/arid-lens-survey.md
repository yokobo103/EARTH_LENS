### 画面に何件出ているか

**全部。58件すべてが、どの縮尺でも描かれている。**
`renderer.ts` のポリゴンに `distanceDisplayCondition` が無い（山脈レンズを直す前と同じ状態）。
距離で消えるのは名札だけで、`labelDistanceForExtent` が地物の広がりから決めている。

名札の優先度（`labelWeight`）を**このレンズは設定していない**ので、値は 0 になる。
`declutterLabels.ts` は重いものから場所を取るので、乾燥帯の名札は港（70/52/36）・
人口（60）・狭窄部（80）・山脈（65/45/28）のすべてに負ける。
`LABEL_WEIGHT.area = 30` という定数は用意されているが、どのレンズからも使われていない。

0.1度の格子で焼き直すと、実際に塗られている陸地は **18,345,319 km2**（単純合計の75%）。
つまり **5,490,000 km2 が二重以上に塗られている**。

塗りは 0.17 のアルファなので、2枚重なると実効 0.31、3枚で 0.43。
**サハラの内側が縁より濃く見えるのは、乾いているからではなく、名前が細かく付いているから。**

## 4. このレンズの主題は何か

3つの候補があった。

| 案 | 何を描くことになるか | 問題 |
|---|---|---|
| A 砂漠という地名 | いまの58件。名前が付いた場所だけ | サハラの中に9件、オーストラリアの乾燥内陸に名前が6つ。**細かく命名された場所ほど濃くなる** |
| B 水が慢性的に少ない土地 | 測った乾燥帯。名前の有無と無関係 | 地名が消える。面を自分で作る必要がある |
| C 人の居住・農業・移動を縛る乾燥条件 | B とほぼ同じ図になる | **レンズ1枚では言えない**（居住は人口レンズ、移動は物流レンズの話） |

**推奨は B。** ただし C は「なぜ半乾燥まで入れるのか」というしきい値の理由として使い、
地点カードや凡例の文には出さない（第一声のルール: そのレンズ1枚で成立することしか言わない）。
A は捨てず、**測った形の上に名前を載せる**（第9節）。

## 6. 何で測るか（候補）

降水量だけでは決められない。同じ 200 mm でも、シベリアでは足りてサハラでは無に等しい。
要るのは「入ってくる水」と「出ていける水（蒸発の需要）」の比。

| 候補 | 解像度 / 期間 | 容量 | ライセンス | オフライン |
|---|---|---|---|---|
| **Köppen-Geiger (Beck 2023)** | 1 km / 1991-2020（1901- も有り） | tif一式 **130.6 MB** | **CC BY 4.0** | 可（figshare 21789074） |
| Global Aridity Index v3.1 (CGIAR) | 30秒 / 1970-2000 | 年値 **645.8 MB**、月値 3.9 GB | **CC BY 4.0** | 可（figshare 7504448） |
| TerraClimate（気候的水不足 CWD） | 4 km / 1958- 各年 | 年ごとに数百 MB | Creative Commons | 可 |
| WorldClim 2.1 / CHELSA | 30秒-10分 | 数百 MB | CC BY 4.0 / CC0 | 可 |

いずれも実行時には使わない。**HydroRIVERS / ETOPO と同じで、重い元データはオフラインで
1回だけ読み、出すのは軽い派生 GeoJSON だけ**にする。

### Köppen B を推す理由

1. **しきい値がそのまま説明になる。** B は「年の降水が、その土地の気温から決まる必要量に
   届かない」。BW（砂漠）は必要量の半分未満、BS（ステップ）は半分以上だが足りない。
   総合スコアではなく、2本の線でしかない。
2. **極の乾燥が自動的に外れる。** 実測: 南極 12,560,033 km2 / グリーンランド 2,160,859 /
   カナダ北極諸島 2,081,901 / シベリア北岸 3,314,028 の**どこにも B は 1% も出ない**。
   Köppen が E（極）を B より先に判定するため。山脈レンズのように南極を手で外す規則が要らない。
   一方 Aridity Index（P/PET）は極を「乾燥」と出しうるので、使うなら除外規則が要る。
3. 容量が桁違いに小さい（130 MB 対 646 MB）。

弱点も書いておく。Köppen は連続値ではなく階級なので「どれくらい乾いているか」の勾配が出ない。
地点カードで「年降水 x mm / 必要量の y%」を出したいなら Aridity Index を後から足す
（両方 CC BY 4.0 なので併用できる）。

## 7. 河川・山脈方式（重い元データ→軽い派生）は使えるか

**属性を足すだけでは足りない。** 河川と山脈は「元のジオメトリは正しいが、どれを出すかの
判断が無い」問題だった。ここは**ジオメトリ自体が実際の乾燥と合っていない**
（本物の砂漠の44%が存在しない）。だから派生させるのは属性ではなく**面そのもの**になる。

0.1度の格子から面を起こして実測した（中央値フィルタ → 2万 km2 未満の島と穴を除去 →
Douglas-Peucker 簡略化、座標は小数2桁）。

```
BW（砂漠）      塊 19  eps=0.05度  頂点  7,022   90 KB / gzip 17.0 KB
BS（ステップ）  塊 35  eps=0.05度  頂点 12,812  165 KB / gzip 30.5 KB
合計                                            255 KB / gzip 47.5 KB
（eps=0.1度まで粗くすると 115 KB / gzip 24 KB、簡略化せず階段のままだと 538 KB）
```

他レンズと比べて十分軽い（rivers 674 KB、physical-features 215 KB、population 1.4 MB）。
**面の数は 54 前後**（今の58件とほぼ同じ、ただし入れ子の二重塗りが無い）。

```

```

## 9. 名前をどうするか

測った面には名前が無い（サハラとアラビアは1つの塊としてつながる）。
**面は測った形、名前は別レイヤ**にする。NE の58件は重心の点として持ち、面の塗りには使わない。
これで「地名としての砂漠」も残る。

ただし NE の名前にも穴がある（モハベ、パタゴニア、オガデン、セチュラが無い）。
名前を足すなら、**外部の明示的な基準を1つ決めて、それを満たすものを全部足す**
（例: Natural Earth の geography_regions_points の Desert 全件、または Wikidata の
desert (Q8514) で面積○○ km2 以上）。今回は決めない。

## 10. 答えておくべき区別

- **砂漠と乾燥帯**: 砂漠（BW）は乾燥帯（B）の一部。今のレンズは名前が「砂漠」の場所だけを
  描いていて、ステップを描いたり描かなかったりしている（カラハリは54%がステップ）。
  段と理由で分ければ、両方を混ぜずに1枚に置ける。
- **半乾燥（サヘル）**: 216万 km2 の帯が丸ごと無い。ここを入れるかどうかがこのレンズの
  性格を決める。入れる理由は「雨に頼る農業が成り立つ限界がここ」だが、**それは文にしない**。
- **極の乾燥**: Köppen では出ない（第6節の実測）。「降水は少ないが乾燥帯ではない」という
  区別が元データ側に入っているので、こちらで規則を足さなくてよい。
- **長期と短期**: 使うのは 1991-2020 の平年値で、**いまの干ばつではない**。
  「この土地はいつも乾いている」だけを言う。干ばつを出すなら実行時データが要るので、
  このレンズの外（別レンズ）になる。

## 11. いまの見た目

本番ビルド（port 8147）で実測。

- **基図と同じ色をしている。** Natural Earth II の陰影図はサハラを砂色で描いている。
  その上に #d9ad62 を 0.17 で塗るので、**乾燥帯レンズを点けても画面がほとんど変わらない**。
  レンズが自分の主題について何も足していない。
- 縁は `outlineColor` 0.56 の1pxで、地球儀に巻くと消える。
- 名札が重なる（サハラ砂漠 / テネレ / リビア砂漠）。優先度 0 なので、
  港や人口を一緒に点けると乾燥帯の名前から消える。
- 入れ子のせいで内側ほど濃い（第2節）。

**方向**: 塗りの色を基図と競わせない。乾きは「色」より「抜け」で出せる
（薄いハッチ、縁だけ、基図側を沈める）。実装時に3案を並べて比べる。

## 12. 重ね合わせ

- **河川**: いちばん効く。ナイルが乾燥帯を貫き、ニジェールが内陸で終わるのが1画面で見える。
  ただし**乾燥帯レンズの文でそれを言わない**（河川レンズ側の話）。
- **人口**: 光が乾燥帯の縁と川沿いだけに並ぶ。今でも読める。
- **港**: 乾いた海岸（ナミブ、アラビア、アタカマ）に港が少ないことが見える。名札の競合に注意。
- **国境**: サハラの直線国境と乾燥帯の形が無関係なことが見える。線が細いので競合しない。

どれも**乾燥帯レンズ側の文には書かない**。重ねたときに気付くのはユーザーの仕事。

## 13. 推奨

1. 主題を B（水が慢性的に少ない土地）に決める。
2. Köppen-Geiger 1991-2020（CC BY 4.0、130 MB）をオフラインで1回読み、
   BW / BS の派生 GeoJSON（合計 gzip 約 48 KB）を焼く。
3. 段は面積で3つ、理由は `perennially_dry` / `seasonal_shortfall` の2つ。総合スコアにしない。
4. NE の58件は名前の点として残す（面には使わない）。
5. 塗りを基図と競合しない見え方に変える。名札に優先度を与える。
6. 焼き直しの検証（`tools/verify-arid-*.mjs`）を `npm run build` に入れる。

## 14. 残る論点

- 名前を足す基準（第9節）。決めるまでは NE の58件のまま。
- 段の境（50万 km2）は塊の分布から取ったが、画面で見て決め直す余地がある。
- BS を国 tier まで下ろすと、インド・中国内陸・地中海が細かく出る。うるさければ
  最小面積を 2万 km2 から上げる。
- Aridity Index を後から足して、地点カードに連続値（P/PET）を出すか。
